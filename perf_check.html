HQAA 포털 속도 진단

느림의 원인이 내 PC/브라우저인지 Apps Script 서버인지 구분합니다. 측정 중에는 다른 탭 작업을 멈춰주세요. (약 30~60초 소요)
이름/사번을 넣으면 로그인이 필요한 API(팀회의 요약, 내 식수 상태)까지 측정합니다. 포털에 이미 로그인한 상태면 자동으로 채워집니다. 비워도 핵심 진단은 가능합니다.

진단 결과

1. 내 PC / 브라우저 성능 (서버와 무관)

2. Apps Script 기본 왕복 시간 (시트 읽기 없음)

존재하지 않는 action을 호출해 네트워크 + Apps Script 실행 준비 시간만 측정합니다. 여기서 이미 느리면 시트 구조와 무관한 구글 인프라/네트워크 문제입니다.

3. API별 응답 시간 (시트 읽기 포함)

순수 시트비용 = 응답시간 − 기본 왕복시간. 이 값이 큰 API가 병목입니다.

4. 홈 화면 실제 로딩 시뮬레이션

홈 화면은 4개 API를 동시에 호출합니다. Apps Script는 같은 사용자의 요청을 동시에 처리하지 못하고 줄 세우는 특성이 있어, 실제로는 합계에 가까운 시간이 걸립니다.
